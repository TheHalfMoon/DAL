# DAL Repository Agent Policy

DAL is research software. Canonical GitHub evidence, frozen scientific artifacts, and the active SpecGrain governance contract override assistant or tool suggestions.

## Communication and provenance

- Communicate with the founder in Arabic. Keep all repository content, code, commands, comments, tests, branches, PRs, issues, evidence, and reviews in English.
- Verify live `main`, the exact PR base/head, protected sources, issue authorizations, and workflow evidence before changing anything. Never treat a historical run or authorization as current.
- Commit only scoped work. Use normal merge commits with exact-head qualification. Do not rebase, squash, force-push, rewrite history, or fabricate evidence.
- Use genuine TypeSafe Jev and checksum-pinned Alibaba OpenCodeReview with their **actual** artifacts, rules, exclusions, and limitations; no Qodo, CodeRabbit, or Cubic substitutes. Complete required CI, Ruff, Mypy, Pytest, manuscript/arXiv and frozen SDK gates at the exact head and after merging when required.

## Graft — zero-cost structural context layer

Adopt the existing Graft integration intent from historical [PR #77](https://github.com/TheHalfMoon/DAL/pull/77), without merging that outdated branch. Use `graft build`, `graft check`, `graft map`, `graft ask`, `graft skeleton`, `graft callers`, and `graft blast --base <base-sha>` for source navigation, changed-unit review, and blast-radius orientation. Confirm installed command syntax with `graft --help` before use.

- Treat generated `graft/` contents as disposable local cache, not a reviewed scientific artifact; never commit its graph or automatic ignore-file changes.
- The wiring graph is **structural evidence only**. Do not describe it as a semantic review or scientific validation. A deep-meaning pass is not qualified unless it actually ran and its complete results are independently verified.
- No paid LLM or cloud integration for Graft. Building and inspecting the structural graph must remain zero founder cost.
- Graft never replaces genuine Jev, Alibaba rules inspection, tests, independent human-readable diff inspection, GitHub Actions evidence, or founder approval.
